# Онлайн-чат без сторонней базы

Онлайн-контур больше не использует Supabase. macOS-приложение не запускает сервер автоматически. Тестовый сервис размещён на `https://dedinsaf.pythonanywhere.com`; этот адрес задан по умолчанию. Актуальное состояние и ограничения описаны в `HOSTING_TEST.md`.

`chat_server/` — заготовка самостоятельной серверной части, а не обязательный сервер на компьютере одного из собеседников. Приведённые ниже команды предназначены для разработки, а не для готового публичного запуска. Перед публикацией необходимы проверка безопасности, HTTPS и проверка связи между реальными устройствами.

## Структура

- `chat_server/` — собственный HTTP-сервер и SQLite-база;
- `online_chat/api.py` — клиент собственного API;
- `online_chat/worker.py` — доставка, синхронизация и статусы;
- `online_chat/storage.py` — локальный атомарный кэш клиента;
- `offlinechat_app.py` — интерфейс и существующий Bluetooth-контур.

Сообщения имеют клиентский UUID, поэтому повтор запроса не создаёт дубль. Статусы меняются только вперёд: `sent → delivered → read`. SQLite работает в WAL-режиме.

## Запуск сервера отдельно

```bash
cd /path/to/Innocamp
OFFLINECHAT_ADMIN_TOKEN='длинный-секрет' python3 -m chat_server.server
```

Проверка:

```bash
curl http://127.0.0.1:8787/health
```

## Запуск через Docker

Создайте `.env`:

```text
OFFLINECHAT_ADMIN_TOKEN=длинный-случайный-секрет
```

Затем:

```bash
docker compose up -d --build
```

Для публичного сервера поставьте перед портом 8787 HTTPS reverse proxy (Caddy или nginx). Сам порт базы наружу не публикуется.

## Адрес сервера в клиентах

Mac использует переменную `OFFLINECHAT_SERVER_URL` либо файл:

`~/Library/Application Support/OfflineChat/online_server.json`

Пример файла:

```json
{"url":"https://chat.example.ru"}
```

iOS позволяет задать адрес в настройках онлайн-чата и сохраняет его на устройстве. Также поддерживается `OfflineChatServerURL` в `Info.plist`. Все клиенты должны обращаться к одному общему сервису; `127.0.0.1` не является адресом общего сервиса. Указание адреса само по себе не разворачивает сервер.

## Очистка своей базы

Сброс доступен только с административным токеном:

```bash
curl -X POST https://chat.example.ru/v1/admin/reset \
  -H 'Content-Type: application/json' \
  -H 'X-Admin-Token: ваш-секрет' \
  -d '{}'
```

Эта операция безвозвратно удаляет профили, сообщения и события.
