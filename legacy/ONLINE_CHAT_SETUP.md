# Настройка онлайн-чата

Новая версия клиента использует RPC-функции Supabase и не обращается к таблицам напрямую.

1. Откройте Supabase Dashboard для проекта.
2. Перейдите в **SQL Editor**.
3. Выполните целиком файл [`supabase_schema.sql`](supabase_schema.sql).
4. Соберите и запустите приложение на двух устройствах.
5. Создайте разные `@username`, найдите пользователя и проверьте статусы:
   - часы — сообщение находится в отправке;
   - одна галочка — сервер принял сообщение;
   - галочка в окружности — устройство получателя получило сообщение;
   - заполненная галочка — получатель открыл диалог;
   - красный значок — отправка не удалась, нажатие повторяет её с тем же UUID.

## Что изменилось в данных

- `chat_profiles` хранит имя, bio, сжатый аватар и хэш локального owner-token;
- `chat_messages` хранит идемпотентный `client_id` и реальный статус доставки;
- `chat_events` даёт клиентам последовательный курсор синхронизации;
- `chat_typing` содержит короткоживущий индикатор набора;
- прямые политики прототипа удаляются, таблицы закрываются RLS, клиенту доступны только ограниченные RPC.

Старые текстовые сообщения автоматически получают события при миграции. Старые служебные строки вида `::oc::...` в новую историю не импортируются.
