# OfflineChat

Для сборки macOS-клиента установите зависимости из `macos/requirements.txt`.

Экспериментальный мессенджер для macOS и iOS: онлайн-переписка через общий
HTTPS-сервис и отдельный существующий Bluetooth-режим.

## Структура

- `macos/` — Python/Tk приложение и модули онлайн-клиента.
- `ios/` — SwiftUI приложение, Xcode-проект и тесты.
- `chat_server/` — Python API, SQLite и WSGI для PythonAnywhere.
- `tests/` — проверки API и моделей.
- `docs/` — состояние тестового хостинга и инструкции.
- `legacy/` — устаревшие Supabase-скрипты и инструкции, **не запускать** для текущего сервиса.

## Проверки

Из корня репозитория:

```sh
PYTHONPATH=macos:. python3 -m unittest discover -s tests
```

Интернет-проверка запускается отдельно и создаёт два тестовых профиля:

```sh
PYTHONPATH=macos:. python3 tests/check_hosted_chat.py
```

## Приложения

Для iOS откройте `ios/OfflineChat.xcodeproj` в Xcode. Для установки на телефон
выберите свою команду подписи. Сборка для симулятора проверена.

Для macOS нужны Python 3.11 с Tk, PyObjC (Cocoa, CoreBluetooth, CoreLocation),
certifi и PyInstaller. Запускайте `python offlinechat_app.py` из `macos/`.
Для сборки приложения: `pyinstaller OfflineChat.spec` из той же папки.
Готовые бинарные сборки и виртуальные окружения не входят в репозиторий.

## Сервис и ограничения

Онлайн-сообщения поддерживают ответы с цитатой, пересылку (включая вложения),
выбор нескольких сообщений и копирование. На iPhone меню открывается удержанием,
на Mac — правой кнопкой мыши. HTTP/HTTPS-ссылки открываются нажатием.
Геопозиция показывается мини-картой MapKit; нажатие открывает Яндекс Карты
(на iPhone — приложение, если установлено, иначе браузер). 2ГИС доступен в меню.
Местоположение — разовая точка, не фоновая трансляция координат.
Ответы, пересылка и геопозиция используют версионированное содержимое `OCM1:`
в поле `body` существующего API; схема БД и авторизация не менялись.
Оба клиента нужно обновить: прежние версии не распознают этот формат.
Предпросмотр записи кружка на Mac обновляется до 30 кадров/с с ограниченной
очередью кадров; реальная плавность зависит также от камеры и нагрузки Mac.

Ссылки карт сформированы по документации [Яндекса](https://yandex.ru/dev/yandex-apps-launch-maps/doc/ru/)
и [2ГИС](https://help.2gis.com/question/developers-launching-2gis-navigation-using-deeplink).

Онлайн-аккаунт создаётся по уникальному username, почте и паролю. Пароль
хранится только в виде PBKDF2-хеша с индивидуальной солью. Регистрация и каждый
новый вход подтверждаются шестизначным кодом из письма; сессия хранится в
Keychain на iOS и в закрытом локальном файле на macOS, а при выходе отзывается.

Для бесплатной доставки кодов на PythonAnywhere поддерживается Brevo HTTPS API.
Перед импортом `chat_server.wsgi` задайте на сервере, но не добавляйте в Git:

```python
os.environ["OFFLINECHAT_BREVO_API_KEY"] = "ключ Brevo"
os.environ["OFFLINECHAT_EMAIL_FROM"] = "подтверждённый отправитель"
os.environ["OFFLINECHAT_EMAIL_FROM_NAME"] = "Связь"
```

Также поддерживается обычный SMTP через переменные `OFFLINECHAT_SMTP_HOST`,
`OFFLINECHAT_SMTP_PORT`, `OFFLINECHAT_SMTP_USERNAME`,
`OFFLINECHAT_SMTP_PASSWORD` и `OFFLINECHAT_SMTP_FROM`.

Лимит файлов в клиентах и на действующем сервере — 50 МиБ
(сервер обновлён и перезагружен 3 октября 2026). Вложения
выбираются через скрепку на iPhone и Mac. Подробности, ограничения и протокол:
[docs/FILES.md](docs/FILES.md).

Тестовый адрес по умолчанию: `https://dedinsaf.pythonanywhere.com`.
Развёртывание: `docs/HOSTING_TEST.md`. Собственная серверная часть не использует
Supabase или FastAPI. WSGI обслуживает короткие запросы; клиенты опрашивают
сервер примерно раз в секунду, пока активны.

Проверены программный обмен сообщениями в обе стороны, доставка и прочтение.
Последние изменения интерфейса собраны, но полная визуальная проверка и
проверка трекпада на реальных устройствах ещё не завершены.

Это пока не готовый защищённый публичный сервис: нет сквозного шифрования,
восстановления забытого пароля и фоновых
push-уведомлений iOS. Используйте тестовые данные. Не публикуйте базы, ключи,
переписки, `.env` и личные настройки Xcode.

На бесплатном PythonAnywhere требуется ежемесячное ручное продление сайта
в панели Web. На момент размещения срок — 25 октября 2026.
