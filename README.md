# OfflineChat

Экспериментальный мессенджер для macOS и iOS: онлайн-переписка через общий
HTTPS-сервис и отдельный существующий Bluetooth-режим.

## Структура

- `macos/` — Python/Tk приложение и модули онлайн-клиента.
- `ios/` — SwiftUI приложение, Xcode-проект и тесты.
- `chat_server/` — Python API, SQLite и WSGI для PythonAnywhere.
- `tests/` — проверки API и моделей.
- `docs/` — состояние тестового хостинга и инструкции.
- `legacy/` — устаревшие Supabase-скрипты и инструкции, **не запускать** для текущего сервиса.

## Проверки

Из корня репозитория:

```sh
PYTHONPATH=macos:. python3 -m unittest discover -s tests
```

Интернет-проверка запускается отдельно и создаёт два тестовых профиля:

```sh
PYTHONPATH=macos:. python3 tests/check_hosted_chat.py
```

## Приложения

Для iOS откройте `ios/OfflineChat.xcodeproj` в Xcode. Для установки на телефон
выберите свою команду подписи. Сборка для симулятора проверена.

Для macOS нужны Python 3.11 с Tk, PyObjC (Cocoa, CoreBluetooth, CoreLocation),
certifi и PyInstaller. Запускайте `python offlinechat_app.py` из `macos/`.
Для сборки приложения: `pyinstaller OfflineChat.spec` из той же папки.
Готовые бинарные сборки и виртуальные окружения не входят в репозиторий.

## Сервис и ограничения

Онлайн-чат поддерживает файлы до 5 МиБ: скрепка на iPhone и кнопка «Файл»
на Mac. Подробности, ограничения и протокол: [docs/FILES.md](docs/FILES.md).

Тестовый адрес по умолчанию: `https://dedinsaf.pythonanywhere.com`.
Развёртывание: `docs/HOSTING_TEST.md`. Собственная серверная часть не использует
Supabase или FastAPI. WSGI обслуживает короткие запросы; клиенты опрашивают
сервер примерно раз в секунду, пока активны.

Проверены программный обмен сообщениями в обе стороны, доставка и прочтение.
Последние изменения интерфейса собраны, но полная визуальная проверка и
проверка трекпада на реальных устройствах ещё не завершены.

Это не готовый защищённый публичный сервис: нет сквозного шифрования,
восстановления аккаунта, полноценного входа с нескольких устройств и фоновых
push-уведомлений iOS. Используйте тестовые данные. Не публикуйте базы, ключи,
переписки, `.env` и личные настройки Xcode.

На бесплатном PythonAnywhere требуется ежемесячное ручное продление сайта
в панели Web. На момент размещения срок — 25 октября 2026.
